# 选型说明（小型公司真实业务的视角）：
#   - Web 框架用 FastAPI 而非 Flask/Django：要异步（调大模型一等公民）+ 自带参数校验
#   - 大模型 SDK 用 openai：千问提供 OpenAI 兼容模式，换供应商只改 base_url

#   - 刻意不装 LangChain：核心链路（agent loop / 检索融合）手写，
#     可控、可调试、面试可讲，框架带来的抽象税在这个体量不划算
#   - SQLite 用 Python 自带标准库，无需依赖
